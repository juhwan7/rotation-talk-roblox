# 소셜 시스템

## 현재 구현

라운드 결과에서 실제 상대에게만 무료 긍정 반응을 한 번 보낸다. 종류는 좋은 친구, 재미있었어요, 대화 잘 통함, 게임 취향 비슷, 친절해요다. 음수·싫어요·외모·연애 점수는 없다. 받은 반응은 본인 화면에서 카테고리별로 확인한다. 타인 전체 프로필 열람은 아직 없다.

서버는 현재 라운드와 쌍, 결과 단계, 발신자의 데이터 상태, 수신자의 데이터 상태를 검증한다. 수신 프로필에 발신자별 마지막 수신 시간을 저장하고 동일 조합의 24시간 이내 중복을 막는다. 수신자는 UTC 일자 기준 하루 최대 10회를 받을 수 있다. 라운드 요청 토큰도 한 번만 소비한다. 로컬 시간이나 클라이언트가 보낸 수신자 ID를 사용하지 않는다.

기본 저장이 성공한 이력은 서버 이동 후에도 제한에 사용된다. 다만 마지막 자동 저장 이후 서버가 강제 종료되면 해당 이력이 유실될 수 있어, 장애 상황까지 정확히 한 번만 지급하는 보장은 아직 없다. 출시 전 별도 지속성 원장과 장애 복구 시험을 완료한다. 부계정·담합 완전 탐지는 미구현이며 다양한 상대 수, 반복 쌍 비율 등을 향후 관찰 지표로 검토한다.

## 안전한 만남

건너뛰기는 즉시 현재 쌍을 종료한다. 재배정 제외는 상대 ID를 프로필에 저장하고 양방향으로 검사한다. 최대 200명이며, 목록 해제 UI가 아직 없어 한도에 도달하면 추가 제외를 거부한다. 출시 전 목록 관리 화면을 추가해야 한다. 이는 Roblox 계정 차단과 별개다. Roblox 신고·차단·음소거는 기본 메뉴에서 처리하도록 안내한다.

## 이후 구현

Talk Again은 결과 화면에서 두 사람이 모두 동의했을 때만 게임 내부 목록에 추가한다. 한쪽 선택을 상대에게 먼저 알리거나 외부 연락처를 요구하지 않는다. 기본 Roblox 친구 요청은 별도 사용자 동의 흐름을 유지한다.

주간 인기 프로필은 신입에게 불리한 누적 절대 순위 대신 최근 긍정 활동의 제한적 소개 형태를 검토한다. 현재 서버 전광판은 테이블 SYNC만 표시한다. 4인 그룹과 서버 공통 선택은 기본 루프의 피로도를 측정한 후 추가한다.
