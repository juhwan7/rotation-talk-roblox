# 게임 기획

## 의도와 기본 루프

Rotation Talk는 작은 공개 라운지에서 선택 카드로 대화를 시작하고 친구를 만나는 게임이다. 이동·사냥이 아닌 사람 사이의 가벼운 상호작용이 중심이다. 성별·나이·실명·연애 선호를 수집하지 않고, 궁합이나 외모를 평가하지 않는다.

서버 12명과 공개 테이블 6개를 기준으로 설계한다. 자동 배정 후 600초간 같은 상대와 함께하고, 20초 결과 화면에서 긍정 반응을 준다. 이후 8초 ROTATE 연출로 로비를 거쳐 다음 상대에게 이동한다. 0~20%는 서로 알아가기, 20~80%는 자유 대화, 마지막 20%는 마무리 선택으로 안내한다. 현재 세 구간은 안내 문구만 다르며 동일한 선택 카드 엔진을 쓴다. 단계별 별도 미니게임은 후속이다.

## 질문과 SYNC

질문 데이터는 별도 모듈에 둔다. 45초 선택 시간과 최대 7초 결과 표시를 사용한다. 양쪽 답변은 서버 메모리에만 보관하며 둘 다 제출하면 같은 틱의 스냅샷에 결과를 전달한다. 네트워크 지연 때문에 물리적으로 동일한 밀리초에 표시되는 것을 보장하지는 않는다. 미응답 시간 초과에는 상대 답을 공개하지 않는다.

같은 선택이면 SYNC 10점. 다른 선택에도 참여 코인은 동일하게 지급한다. SYNC는 해당 라운드에서만 유지한다. 중앙 전광판은 상위 3개 테이블을 표시하고 개인 하위 순위는 만들지 않는다. 최고 점수 동률은 모두 Best Duo 보상 대상이며 0점에는 보너스가 없다.

## 상대 배정

현재 인원의 가능한 최대 쌍을 찾고 직전 상대를 다시 만나는 비용을 크게 둔다. 홀수 인원 대기자는 다음 라운드 우선순위를 높인다. 재배정 제외는 어떤 경우에도 완화하지 않는다. 두 명뿐인 경우 같은 상대가 다시 배정될 수 있다. 이는 다른 상대가 존재하지 않는 경우의 명시적 예외다.

중간 입장자는 다음 라운드까지 대기한다. 퇴장·건너뛰기가 발생한 쌍은 취소하고 두 사람 모두 대기 공간으로 이동한다. 활동 중인 쌍이 없으면 8초 뒤 다시 배정한다. 최대 대기 시간 문제는 실제 플레이에서 측정해 보충 매칭을 검토한다.

## 발전 방향

MVP 뒤 Alpha 단계에서 양쪽 동의 Talk Again, 3회 1:1 뒤 4인 그룹, 서버 공통 투표를 추가한다. 그룹에서는 공동 선택과 협동 점수를 중심으로 설계한다. Fast Choice, Emoji, Yes/No, Mystery, Double SYNC는 질문·라운드 설정을 확장하는 별도 모드로 검토한다.

장기 수집은 Topic Card, 프로필 테마, 칭호, 이모트, 테이블·의자 스킨, 등장 효과, 종료 포즈다. 현재 저장 필드만 예약되어 있으며 수집·장착 기능은 구현하지 않았다. 수익화는 외형 표현 중심으로 하며 점수나 평판을 판매하지 않는다.

## 사용자 화면 원칙

현재 상대·남은 시간·SYNC·총 코인·라운드 획득량을 항상 읽을 수 있게 한다. 선택 버튼은 46픽셀 높이를 사용하고 모바일에서 패널을 스크롤할 수 있게 한다. 신고·차단 안내와 건너뛰기를 제공한다. 실제 모바일 안전 영역, 채팅창 겹침, 가로·세로 화면은 Studio 기기 에뮬레이션으로 확인해야 한다.
