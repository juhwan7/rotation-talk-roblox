# 학교 강당 디자인

요청 및 적용일: **2026-09-27**. 사용자가 학교 강당 분위기를 요청했다. 게임의 핵심은 공개된 장소에서 서로 대화하는 것으로 유지한다.

## 공간의 인상

학교 행사 전 친구들이 모이는 따뜻한 강당을 목표로 한다. 목재 바닥, 크림색 벽, 높고 큰 창문, 천장 보, 붉은 주름 커튼, 무대 연단, 초록 칠판형 전광판을 사용한다. 실제 학교 이름·로고·교복을 가져오지 않는다. 무대가 보이는 개방 구조이고 커튼 뒤에 들어가는 개인실은 만들지 않는다.

## 배치

강당 바닥은 168×200 스터드(Roblox 공간 길이 단위), 천장 높이는 29다. 북쪽(-Z)에 무대, 남쪽(+Z)에 입구·대기 공간을 둔다. 20개 대화 테이블 중심은 X=-42/-14/14/42, Z=-20/8/36/64/92의 4열×5줄이다. 각 테이블에는 서로 마주 보는 나무 의자 2개, 초록 매트, 질문 카드와 양면 번호판을 둔다.

테이블 매트는 18×20으로, 좌우 10·앞뒤 8 스터드 간격을 남긴다. 관람석은 양쪽 가장자리에만 두고 중앙 동선을 비운다. 관람석은 장식용 Part이며 매칭용 Seat는 정확히 40개다. 입장·건너뛰기 복귀 지점은 (0,5,117)이며 무대를 바라본다. 입구 양쪽 게시판에 활동 순서와 안전 약속을 보여준다.

무대 칠판과 입구 게시판은 +Z 방향에서 읽도록 뒷면(Back)에 글자를 표시한다. 이는 사람의 시선 기준이며 '뒤에 숨긴 글자'라는 의미가 아니다. 테이블 번호판은 양면에 표시한다.

## 색상과 화면

`Theme.luau`에서 종이색·초록색·목재·커튼 색을 공유한다. 화면 위에는 초록 학교 표지판을 고정하고 아래에는 크림색 활동 카드를 스크롤하게 한다. 짙은 녹색 글자로 대비를 확보하고 버튼 높이 46픽셀은 유지한다. 초기 데이터를 받기 전 선택·반응·건너뛰기 버튼은 감춘다.

## 구현과 검증 경계

외부 유료 에셋이나 다운로드한 메시 없이 기본 도형으로 생성한다. 넓은 목재 판과 몇 개의 천장 조명을 사용해 물체·동적 조명을 불필요하게 늘리지 않는다. 천장은 실제로 존재하므로 카메라가 가려지는 상황, 실제 조명 밝기, 관람석과 테이블 사이 이동은 Studio에서 확인해야 한다.

현재 소스 컴파일과 장소 빌드는 통과했다. 기존 라운지의 1인 실행은 확인했지만 **학교 강당 디자인의 실제 Studio 화면은 아직 확인하지 못했다.** 자동 승인 검토의 사용량 한도 오류로 해당 세션의 Studio 작업이 보류되었다. 파일을 연 후 Play해야 공간과 화면이 생성된다.
