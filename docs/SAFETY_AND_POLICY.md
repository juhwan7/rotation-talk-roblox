# 안전과 정책

검토 기준일: **2026-09-27**. 이 문서는 구현 방향과 출시 전 점검 목록이며 Roblox의 승인 결과가 아니다.

## 채팅

게임은 Roblox의 기본 TextChatService와 기본 채널을 사용한다. 별도 채팅 입력창, 사용자 메시지를 RemoteEvent로 전달하는 우회 채팅, 필터링되지 않은 커스텀 말풍선을 만들지 않는다. 계정별 채팅 가능 여부와 연령·개인정보 설정은 Roblox가 적용한다. 질문은 개발자가 작성한 고정된 게임 데이터이며 자유 입력 질문은 없다.

공식 [Chat system guidelines](https://create.roblox.com/docs/chat/guidelines)는 게임 내 채팅의 TextChatService 사용과 개인정보 설정 존중을 요구한다. 향후 테이블별 직접 채팅 채널을 도입한다면 SetDirectChatRequester 등 공식 설정을 별도로 적용해야 한다. 현재 1:1 비공개 채널을 구현하지 않았다.

## 공간·콘텐츠

벽으로 가린 개인실 대신 같은 공간에서 모두 볼 수 있는 테이블을 둔다. 실명·나이·주소·학교·전화·외부 연락처를 수집하지 않는다. 실제 연애 상대 검색, 성별 조건 매칭, 외모 평가, 연애 궁합 표현을 제공하지 않는다. SYNC는 같은 선택의 누적 게임 점수다.

주요 활동이 대화와 교류인 만큼 Social Hangout(사람들이 모여 교류하는 경험) 분류 가능성을 검토해야 한다. 공개된 공간만으로 모든 연령 허용을 보장할 수 없다. 게시 시 최신 성숙도 설문과 [Restricted Content Policy](https://en.help.roblox.com/hc/en-us/articles/15869919570708-Restricted-Content-Policy)를 다시 확인하고 실제 기능에 맞게 답한다.

## 신고·차단·음소거

현재 게임의 안내 버튼은 Roblox 기본 메뉴의 신고·차단·음소거 사용법을 보여준다. 신고를 접수하거나 제출 완료를 표시하지 않는다. 건너뛰기와 게임 내부 재배정 제외는 구현했지만 계정 차단·채팅 음소거와는 구별된다. 음성 채팅은 별도 활성화하지 않았고 음성 제한을 우회하지 않는다.

## 출시 전 필수 확인

- 실제 계정의 차단 상태가 채팅·음성에 적용되는지 확인하고, 플랫폼 차단 목록을 매칭 제외와 연계하는 기능을 검토한다. 현재 게임 내부 제외 목록만 매칭에 사용한다.
- 접근 가능 연령, 소셜 경험 분류, 플랫폼 개인정보 설정을 실제 게시 환경에서 확인한다.
- Roblox 신고·차단 메뉴가 PC·모바일에서 안내와 일치하는지 확인한다.
- 다른 사람의 답을 미리 복제하지 않는지 다중 클라이언트로 검사한다.
- 저장 장애·세션 잠금·서버 강제 종료 시험을 통과하고 장애 중 평판 중복 가능성을 해결한다.
- 기본 채팅 UI와 게임 패널의 겹침, 화면 방향별 터치 접근성을 검사한다.
