# TalkCoin 경제

TalkCoin은 게임 안에서만 쓰는 재화다. 현재 구매·양도·현금 환전·Robux 교환 기능이 없다.

| 항목 | 초기 값 | 조건 |
|---|---:|---|
| 질문 참여 | +5 | 현재 질문 첫 유효 선택 한 번 |
| 활동 5분 | +50 | 최근 90초 안에 유효한 질문 선택, 실제 라운드 참여 시간 누적 |
| 라운드 완료 | +100 | 선택 3회 이상, 설정 라운드 길이의 50% 이상 활동 |
| Best Duo | +20 | 완료 조건 충족 + 최고 SYNC 공동 1위, 0점 제외 |

서버에서 1초 단위로 활동을 계산한다. 서버가 멈춘 시간은 한 틱 최대 2초까지만 인정하여 과지급을 줄인다. 질문을 빠르게 다 고르면 라운드당 선택 기회가 늘어나므로 수입 상한은 45초 질문 간격이 아닌 7초 결과 간격에 의해 정해진다. 이 초기 규칙은 빠른 응답 쌍의 수입을 늘리는 단점이 있어 QA에서 반드시 측정한다. 자동 클릭을 완전히 탐지하는 구조는 아니다.

채팅 글자 수·메시지 수로 보상하지 않는다. 활동 시간은 라운드 사이에 누적되지만 접속을 끊으면 초기화한다. 로비·결과·회전 시간에는 누적되지 않는다. 질문 참여 보상은 상대가 끝내 답하지 않아도 지급하되 같은 질문 중복은 불가능하다. 완료 전에 나간 경우 이미 획득한 참여 코인만 남는다.

## 소비 계획과 인플레이션

상점은 미구현이다. 시험 가격 후보: 기본 프로필 테마 500, 칭호 1,000, 의자 색상 2,000, 희귀 회전 연출 5,000. 확정 가격이 아니며 활동 1시간의 실제 수입, 구매까지 걸리는 시간, 신규 유저의 접근성을 측정한 뒤 조정한다. 랜덤 유료 상자는 도입하지 않는다.

평판은 MVP에서 무료다. 향후 TalkCoin 25를 사용하는 High Five 같은 시각 효과를 추가할 수 있으나 무료 반응과 평판 증가량은 같아야 한다. 코인 유료 판매를 도입하더라도 평판이나 경쟁 점수로 연결하지 않는다.

코인 최대치는 10억으로 제한한다. 요청에 금액을 받지 않고 고정된 서버 설정만 사용한다. 영구 저장은 60초 간격이므로 서버 강제 종료 시 마지막 저장 이후 획득분이 유실될 수 있다. 출시 전 더 강한 영수증·거래 보장을 검토한다.
