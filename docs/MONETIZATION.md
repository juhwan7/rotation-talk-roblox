# 수익화 원칙

현재 **Robux 결제는 구현하지 않았고 상품 ID도 없다.** 첫 단계에서는 핵심 대화·선택·보상 경험을 검증한다.

Game Pass는 일회 구매 후 계속 사용할 수 있는 권한이다. VIP 프로필 외형, 전용 이름 장식, 회전 연출처럼 꾸미기에만 사용한다. Developer Product는 반복 구매 가능한 상품이다. 도입한다면 확정된 외형 또는 명확한 편의 상품을 대상으로 하고, 서버의 구매 영수증 처리와 중복 지급 방지를 먼저 완성한다.

유료 구매로 평판, SYNC, Best Duo 승률, 상대 선택권을 올리지 않는다. TalkCoin 구매와 유료 특별 반응을 함께 도입하면 평판을 간접 구매하는 경로가 될 수 있으므로 효과는 외형만 다르게 하고 평판 횟수·수치는 무료와 같게 유지한다. 유료 랜덤 상자나 불리한 시간 압박 구매는 첫 계획에서 제외한다.

게임 패스·반복 상품의 실제 정책과 지원 상태는 구현 시 Roblox 공식 문서를 다시 확인한다. 출시 수익 배분이나 환산 수치는 현재 기획에 확정하지 않는다.

공식 참고: [Passes](https://create.roblox.com/docs/production/monetization/passes), [Developer products](https://create.roblox.com/docs/production/monetization/developer-products). 정책 준수 승인이나 수익 보장을 의미하지 않는다.
