# 다음 개발자를 위한 인수인계

마지막 작업: **2026-09-27 / 최초 MVP 소스 구축**. 저장소 `juhwan7/rotation-talk-roblox`는 작업 시작 시 비어 있었다. 다른 프로젝트에서 파일을 가져오거나 기존 코드를 교체하지 않았다.

## 현재 상태

첫 플레이 루프와 한국어 문서, 장소 빌드 도구가 구현되어 있다. 운영 소스 전체가 Luau 컴파일을 통과했고 순수 규칙 91개와 모의 서버 통합 43개를 통과했다. Node 빌드와 Rojo 빌드도 성공했다. **실제 Studio 2~12명 시험과 실제 데이터 저장 검증은 아직 하지 않았다.** 현재 대화에는 Studio 제어용 연결 도구가 제공되지 않았다.

`src/shared/Config.luau`에서 모든 시간·보상을 관리한다. 기본 600초, 결과 20초, 회전 8초. `QuestionData.luau`에 질문 16개가 있다. `Rules.luau`는 독립 시험 가능한 규칙이고 서버 모듈은 Round/Match/World/Economy/Reputation/Data 역할로 나뉜다. 클라이언트는 서버 스냅샷만 보여주며 보상량을 요청하지 않는다.

## 우선순위

1. `node tools/build.mjs`로 생성하거나 제공된 장소 파일을 Studio에서 열고 QA의 2명 시나리오부터 실제 검증한다.
2. 3·4·12명 배정, 중도 퇴장, 리셋, 답변 비공개, 로테이션을 검증한다.
3. 별도 테스트 저장소로 자동 저장·동시 세션·서버 종료·재접속·오류 주입을 시험한다. 강제 종료 이후 평판 중복 가능성을 지속 원장 방식으로 개선한다.
4. 모바일 세로·가로, 채팅창 겹침, 실제 신고·차단 안내를 검사하고 재배정 제외 목록 해제를 추가한다.
5. 최소 질문 간격과 시간당 코인 수입을 측정한 뒤 상점·수집을 추가한다.

## 아직 하지 않은 것

그룹 라운드, 서버 투표, Talk Again, 수집·장착·상점, 과금, 실제 부계정 탐지, 공개 배포. 저장 구조의 cosmetics/titles/cards/settings는 예약 필드다. 평판은 현재 무료이며 코인 특별 효과는 후속이다. 신고·차단·음소거는 기본 Roblox 메뉴를 사용한다. 게임 내부 재배정 제외를 계정 차단이라고 부르지 않는다.
