# 다음 개발자를 위한 인수인계

마지막 작업: **2026-09-27 / GitHub 최신 장소 파일 자동 배포**. 저장소 `juhwan7/rotation-talk-roblox`는 최초 작업 시작 시 비어 있었다.

## 현재 상태

`.github/workflows/studio-download.yml`은 main 업데이트 또는 수동 실행 시 공식 Luau 0.740 도구의 지문을 확인하고 전체 코드 검사 후 장소 파일을 생성한다. 최신 main과 일치하는 실행만 다운로드용 개발 빌드를 배포한다. README의 고정 Releases 최신 링크로 받는다. `tools/release-info.mjs`는 원본 커밋과 파일 지문을 남긴다. 실제 원격 실행 기록은 GitHub Actions와 Releases에서 확인한다. 실패 시 최신 링크가 이전 성공 파일을 가리킬 수 있다는 점을 사용자에게 알려야 한다. Roblox에는 자동 게시하지 않는다.

첫 플레이 루프와 학교 강당 디자인, 한국어 문서, 장소 빌드 도구가 구현되어 있다. 운영 소스 전체가 Luau 컴파일을 통과했고 순수 규칙 483개, 모의 서버 통합 156개, 매칭 그래프 33,868개를 통과했다. Node 빌드와 Rojo 빌드도 성공했다. **기존 라운지의 실제 Studio 1인 시작은 통과했지만 새 학교 강당 디자인, 2~40명 시험과 실제 데이터 저장은 검증 전이다.**

사용자가 Studio의 MCP 스위치를 켠 뒤 공식 StudioMCP stdio 연결로 프로젝트 읽기·수정·플레이 실행에 성공했다. 미게시 장소의 임시 저장 초기화 오류를 수정했다. 이후 화면 캡처 요청에서 자동 승인 검토가 사용량 한도 오류로 완료되지 않아 Studio 후속 작업을 중단했고, 학교 강당은 로컬 코드·파일만 변경했다. 다음 작업자는 도구 목록과 실제 열린 Studio를 다시 확인해야 한다. 현재 열려 있는 Studio는 기존 라운지 시험 세션일 수 있으므로, 사용자 작업을 보존한 뒤 최신 파일을 열거나 변경 모듈을 동기화한다.

`src/shared/Config.luau`의 TableCount=20, TableColumns=4, MaxPlayers=TableCount*2로 정원을 관리한다. Roblox 게시 장소의 MaxPlayers는 별도 설정이며 40명 적용은 아직 미완료다. 같은 파일에서 모든 시간·보상을 관리한다. 기본 600초, 결과 20초, 회전 8초. `QuestionData.luau`에 질문 16개가 있다. `Rules.luau`는 독립 시험 가능한 규칙이고 서버 모듈은 Round/Match/World/Economy/Reputation/Data 역할로 나뉜다. 클라이언트는 서버 스냅샷만 보여주며 보상량을 요청하지 않는다.

## 우선순위

1. `node tools/build.mjs`로 생성한 학교 강당 파일을 Studio에서 열고 Play한 뒤 무대·칠판 면 방향·카메라·통로·화면을 확인한다. 그다음 QA의 2명 시나리오로 진행한다.
2. Studio 3·4명 및 비공개 경험 20·39·40명 배정, 중도 퇴장, 리셋, 답변 비공개, 로테이션을 검증한다.
3. 별도 테스트 저장소로 자동 저장·동시 세션·서버 종료·재접속·오류 주입을 시험한다. 강제 종료 이후 평판 중복 가능성을 지속 원장 방식으로 개선한다.
4. 모바일 세로·가로, 채팅창 겹침, 실제 신고·차단 안내를 검사하고 재배정 제외 목록 해제를 추가한다.
5. 최소 질문 간격과 시간당 코인 수입을 측정한 뒤 상점·수집을 추가한다.

## 아직 하지 않은 것

그룹 라운드, 서버 투표, Talk Again, 수집·장착·상점, 과금, 실제 부계정 탐지, 공개 배포. 저장 구조의 cosmetics/titles/cards/settings는 예약 필드다. 평판은 현재 무료이며 코인 특별 효과는 후속이다. 신고·차단·음소거는 기본 Roblox 메뉴를 사용한다. 게임 내부 재배정 제외를 계정 차단이라고 부르지 않는다.
