# Rotation Talk Roblox

**학교 강당에서 가벼운 질문을 함께 고르고, 일정 시간마다 새로운 상대를 만나는 소셜 선택 게임.**

현재 단계: **Studio 연결 및 기존 라운지의 1인 시작 검사 통과 / 학교 강당 디자인 소스·빌드 완료 / 새 디자인 실제 화면과 다중 접속은 검증 전**. 연애·소개팅 서비스가 아니며 SYNC는 선택 게임 점수다. 초기 저장소는 비어 있었고 2026-09-27 최초 구현을 시작했다.

## 구현한 플레이 흐름

학교 강당 디자인: 목재 바닥, 높은 창문, 붉은 커튼 무대, 칠판형 전광판, 연단, 양옆 관람석, 입구 안내 게시판. 중앙 4열×5줄 테이블은 가리지 않고 서로 보이게 배치했다. 화면은 초록 학교 표지판과 크림색 활동 카드 스타일이다. 색상은 `src/shared/Theme.luau`에서 관리한다. [디자인 기준](docs/ART_DIRECTION.md).

최대 40명 → 공개된 20개 2인 테이블 → 10분 대화와 비밀 선택 → 같은 선택이면 SYNC +10 → 20초 결과·긍정 평판 → 8초 ROTATE → 다음 상대 배정.

- 16개 한국어 질문, 8개 주제 분류, 둘 다 선택한 뒤 결과 공개.
- 서버 기준 시간·점수·코인·평판. 잘못된 선택·중복 제출·이전 질문 요청·과도한 요청 거부.
- 질문 +5, 활동 5분 +50, 조건 충족 라운드 완료 +100, 공동 Best Duo +20.
- 평판 5종, 라운드당 한 번, 같은 상대 24시간 제한, 수신자 하루 10회 한도.
- 상대 건너뛰기, 저장되는 재배정 제외, Roblox 신고·차단·음소거 안내.
- 저장 세션 잠금, 60초 자동 저장, 퇴장·서버 종료 저장, 불러오기 실패 시 입장 중단.
- 홀수 인원 대기, 최근 상대 회피, 대기자 우선, 중도 퇴장 시 남은 상대 로비 복귀.
- 작은 화면에서 스크롤 가능한 한국어 플레이 UI(사용자 화면), 개인 평판 요약, 서버 전광판.

**아직 구현하지 않은 것:** Talk Again, 4인 라운드, 서버 투표, 상점·코스메틱 장착, Robux 결제, 이상 행동 분석, 앱 내 차단 목록 관리. 신고·차단·음소거는 Roblox 기본 기능을 이용하며 이 게임의 재배정 제외와는 별도다.

## 실행

Node.js가 있으면 외부 패키지 설치 없이 다음 명령으로 Studio에서 열 수 있는 XML 형식 장소 파일을 만든다.

```sh
node tools/build.mjs
```

1. Roblox Studio에서 `build/RotationTalk.rbxlx`를 연다. 맵과 화면은 플레이 시작 시 생성된다.
2. 테스트용 비공개 경험으로 저장한다. 공개하지 않은 로컬 파일에서도 임시 데이터로 시험할 수 있다.
3. Studio의 서버 및 클라이언트 테스트 기능으로 **2명**, 다음 **3·4명**을 실행한다. 20·39·40명 부하 시험은 별도 비공개 경험에서 실제 참여자로 수행한다. 시험 절차는 [QA](docs/QA.md).
4. 기본 라운드는 600초. `src/shared/Config.luau`의 `RoundSeconds`를 180/300/420/600으로 바꿀 수 있다. 시험 때 180초를 권장하되 5분 보상은 여러 라운드 누적으로 별도 확인한다.
5. Studio에서는 `StudioPersistence = false`로 실제 저장을 하지 않는다. 저장 시험은 별도 테스트 경험 및 `StoreName`에서만 `true`로 바꾸고 Studio API 접근을 허용한다. 운영 데이터를 Studio 시험에 사용하지 않는다.
6. 게시할 경험의 최대 인원을 Creator Dashboard에서 **40명**으로 설정한다. 코드도 40명을 초과한 입장을 거부하지만 게시 설정을 대신하지 않는다.

Rojo(파일을 Studio 구조와 동기화하는 개발 도구)를 사용하는 경우 `default.project.json`도 제공한다. 필수는 아니다. `src`가 원본이며 생성된 장소 파일을 직접 고친 경우 원본에도 반영해야 한다.

## 검사

Luau 공식 명령행 실행기가 있다면:

```sh
luau tests/rules.spec.luau
node tools/test.mjs /path/to/luau /path/to/luau-compile
node tools/build.mjs
```

자세한 결과와 미검증 범위는 [TEST_RESULTS](docs/TEST_RESULTS.md)에 기록한다. 명령행 시험은 실제 Roblox 네트워크·물리·채팅·DataStore 서비스 검증을 대체하지 않는다.

## 구조와 다음 단계

`src/shared`: 설정·질문·순수 규칙. `src/server`: 라운드·매칭·월드·경제·평판·저장. `src/client`: 한국어 화면 및 입력. `tools`: 장소 빌드와 검사. `tests`: 규칙 및 서버 통합 시험. `docs`: 기획·결정·로드맵·검증·인수인계.

**최근 업데이트 — 2026-09-27:** Studio 실제 연결과 기존 라운지 1인 실행을 확인했다. 미게시 장소가 임시 모드에서도 온라인 저장소에 접근하던 시작 오류를 수정하고 재발 검사 5개를 추가했다. 이어 사용자 요청에 따라 학교 강당 공간과 활동 카드 화면으로 변경했다. 새 디자인은 로컬 빌드까지 완료했으며, 자동 승인 검토의 사용량 한도 오류로 Studio 반영·시각 검증은 보류했다. 추가 요청에 따라 20개 테이블·40명 정원, 4열×5줄 강당으로 확장하고 대규모 상대 배정 알고리즘을 교체했다. 규칙 483개, 모의 서버 156개, 매칭 그래프 33,868개 검사를 통과했다. Roblox 게시 설정의 최대 인원 40명은 아직 적용하지 않았다. 다음 우선순위는 최신 강당 실제 화면·다중 접속·40명 부하 시험이다.
